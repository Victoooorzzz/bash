# Herramientas de Automatización en Bash

Este repositorio contiene scripts de administración y mantenimiento para Linux.

## Funciones Principales

###  Menú Principal
El sistema cuenta con un menú interactivo que utiliza la función **organizar**.
Esta utilidad permite ordenar y clasificar archivos automáticamente para mantener el directorio limpio.

###  Script de Salud (health.sh)
Herramienta de monitoreo rápido que muestra en tiempo real:
- **Uso de Disco:** Porcentaje de espacio ocupado.
- **Memoria RAM:** Cantidad de memoria en uso actualmente.
